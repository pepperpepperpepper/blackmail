## Design instruction
The developer should keep a local visual-reference board showing:
- primary old screenshot,
- current app screenshot from simulator,
- side-by-side differences.

For each UI review, compare:
- pane widths,
- row heights,
- font sizes,
- toolbar icon positions,
- separator insets,
- selection color,
- whitespace,
- navigation title scale.
